# 세션 인계 요약 (클라우드 → 로컬)

작성일: 2026-10-12 / 브랜치: `claude/friendly-einstein-d40r7j`

## 프로젝트 목표
- 3D 게임 제작. 용도는 **취업용 포트폴리오** (출시는 부차적). 희망 직무는 아직 미정.
- 역할 분담: 기획은 사용자와 협의, 코드·에셋 제작·문서화는 Claude.

## 확정된 결정
- **엔진: Unity** (최신 LTS, URP 사용). 검토했던 후보: Godot, Unreal, Roblox Studio.
  - Godot을 한 번 선택했다가 국내 채용 시장에서 Unity 비중이 커서 Unity로 변경.
- **장르: 로우폴리 로그라이크 던전 크롤러** (후보 5개 중 1번 선택)
- 시점: 쿼터뷰 고정 카메라 / 전투: 근접 위주 / 분위기: 던전 판타지(Claude가 정한 기본값)
- 조작: 키보드+마우스 (게임패드는 후순위) / 목표 기간: 3개월(Claude가 정한 기본값, 변경 가능)

## MVP 범위
| 영역 | 내용 |
|---|---|
| 플레이어 | 이동, 구르기, 기본 공격 1종, 스킬 1~2종 |
| 적 | 3종(근접, 원거리, 돌진형) + 보스 1종 |
| 던전 | 모듈식 방 10~15개를 조합해 절차적 구성, 한 층 5~8개 방 |
| 보상 | 방 클리어 후 3택1 |
| 영구 성장 | 죽을 때 얻는 재화로 시작 능력치 강화 |
| UI | 체력바, 스킬 쿨다운, 보상 선택창, 메인 메뉴 |
| 연출 | 히트 스톱, 카메라 흔들림, 파티클, 사운드 |

## 포트폴리오 포인트
절차적 방 생성, 상태 머신 기반 적 AI, ScriptableObject 데이터 기반 설계, 게임 느낌(연출).

## 에셋 전략
- 로우폴리 스타일, 색상 팔레트 5~8색으로 통일.
- 무료 CC0 에셋(Kenney, Quaternius, Poly Haven) + 코드/에디터 스크립트로 만든 기본 도형 조합.
- 캐릭터·핵심 모델은 AI 생성(Meshy, Tripo 등)을 사용자가 .glb로 제공하는 방식 검토.
  상업적 이용·라이선스는 각 서비스 약관을 직접 확인할 것.
- 취업용이므로 외부/AI 에셋 사용 부분은 문서에 출처를 명시할 것.

## 설치한 스킬(사용자가 설치 완료했다고 알림)
- Unity 공식 플러그인 (new-unity-project, physics-3d-collision, initialize-ai-navigation, urp-postprocessing, ui 계열, audio-setup-mixers 등)
- unity-perf (C# 코드 규칙, 성능 최적화)
