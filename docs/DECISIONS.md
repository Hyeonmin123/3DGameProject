# 의사결정 기록

## 2026-10-12 엔진: Godot 4
- 목적: 취업용 포트폴리오 (출시는 부차적)
- 후보: Unity, Unreal, Roblox Studio, Godot
- 선택 이유: 프로젝트 파일이 텍스트 기반이라 코드/씬을 직접 작성·버전관리하기 좋고, 라이선스 비용이 없음
- 알려진 약점: 국내 게임 업계 채용은 Unity/Unreal 비중이 큼
  - 대응: 설계 문서·코드 구조·플레이 영상으로 설계 역량을 강조
  - 대응 후보: 언어를 C#(.NET)으로 선택하면 Unity 이전이 쉬움 (웹 내보내기 제약 있음)
